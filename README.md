# 成本報價管理系統 (Cost & Quote System)

本專案是一個基於 **Java 標準視窗技術 (Swing/AWT)** 開發的桌上型應用程式。主要功能為提供企業或業務人員進行**產品成本估算、利潤分析與自動化報價生成**。專案採用標準的 MVC（模型-視圖）分離設計思維，具備良好的模組化結構。

---

## 🛠️ 技術棧與開發環境
* **程式語言：** Java SE
* **圖形介面：** Java Swing / AWT 視窗元件
* **整合開發環境 (IDE)：** Eclipse IDE (專案內含 `.project` 與 `.classpath` 配置)

## ⚙️ 核心模組詳細說明

### 1. 資料與計算核心：`quote.java`
作為系統的後端邏輯層，主要處理純資料運算與模型封裝：
* **欄位封裝：** 定義產品基礎成本、原料、人工、運費等各項成本欄位（Getter/Setter）。
* **報價公式演算法：** 內建自動計算邏輯，可依據設定的「毛利率」或「加成比例」，動態推算建議售價與總利潤。
* **資料驗證：** 負責防呆機制，確保介面傳入的數字格式正確，避免運算出錯。

### 2. 圖形使用者介面：`quoteUI.java`
作為系統的前端表現層，建構直覺的視覺化操作視窗：
* **介面佈局：** 使用 Swing 元件（如 `JFrame`、`JPanel`、`JTextField`、`JButton`、`JLabel`）搭建表單。
* **即時互動：** 專案中編譯出的 `quoteUI$1.class` 至 `quoteUI$6.class` 代表視窗內綁定的 **6 個事件監聽器 (Event Listeners)**，分別處理：
  * **按鈕點擊事件：** 如「執行計算」、「清除欄位」、「匯出報價」等功能。
  * **焦點/輸入監聽：** 當使用者在欄位輸入數值時，即時觸發背景的 `quote` 進行連動計算，達到免手動點擊、即時預覽的效果。

---

## 🚀 系統核心工作流程
1. **輸入數據：** 使用者於 `quoteUI` 視窗中輸入各項成本細項（如原物料費、預期利潤率）。
2. **邏輯處理：** 介面監聽器擷取數值，並傳遞給 `quote` 類別進行報價核心公式計算。
3. **動態反饋：** 運算結果即時回傳，並更新在 `quoteUI` 的報表或售價標籤上。
